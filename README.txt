# Birthday Website

Open `index.html` to start.

## Personalize
Open `script.js` and edit the CONFIG object:
- friendName
- giftMessage
- memories (icon, front, back)

## Files
- index.html — opening page
- birthday.html — birthday + gift page
- memories.html — memories + final surprise
- style.css — all styling and animations
- script.js — personalization + interactions

No external libraries or images are required.
